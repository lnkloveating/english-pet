# MVP 路线图（6 周）

## 第 0 周：合同与演示骨架

- 三服务可启动，客户端可看到 stub 回合
- 冻结 `/v1` 最小合同和黄金 payload
- 统一匿名 ID、事件名、错误结构

## 第 1–2 周：核心说话闭环

- 录音/ASR Provider 接入与超时降级
- Agent 三类模式：repeat → choose → answer
- 有效开口、基础/bonus 声果与简单成长
- 20–50 个黄金对话评测

## 第 3–4 周：自适应与宠物创建

- 学习者画像跨会话更新
- 引导式 → 场景式 → 自由式难度迁移
- 描述结构化、概念图生成与安全审核
- 家长简单报告：有效开口、主动开口、平均句长、连续轮数

## 第 5–6 周：小规模试用

- 真实设备延迟、成本、失败恢复和可观测性
- 监护人同意、删除、保留期限和内容安全联调
- 用核心 KPI 判断下一步：每周有效英语开口次数是否持续增加

## 暂不进入 MVP

- 完全从零的自动 3D 建模、自动 rig
- 自训练大模型或基于未审查儿童数据的微调
- 大地图、复杂装扮商城、排行榜和公开社交
